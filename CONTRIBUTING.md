Thank you for your interest in contributing to Dolphin.

## Before contributing

- Discuss substantial architectural changes in an issue before implementing them.
- Keep changes focused and explain their motivation.
- Do not commit passwords, signing keys, keystores, access tokens, or private data.
- Preserve Dolphin's least-privilege permission model and WebView origin checks.
- Add or update tests and documentation when behavior changes.
- Report security vulnerabilities privately to the repository maintainer rather
  than publishing exploitable details in a public issue.

## Pull requests

Include a clear summary, relevant test results, known limitations, and any
security or compatibility implications. Do not claim device validation unless
the change has actually been tested on a physical device or emulator.
